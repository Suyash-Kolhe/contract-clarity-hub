# Contract Clarity Hub

Build a legal document assistant web app. Users upload a PDF or DOCX contract. The app extracts the text, sends it to Gemini to generate: (1) a plain-language summary, (2) a clause-by-clause table tagging each clause as Obligation / Risk / Standard / Ambiguous with a one-line explanation, (3) a chat interface where the user can ask questions answered only from the uploaded document, (4) an exportable checklist of 'questions to ask a lawyer.' Add a persistent disclaimer that this is not legal advice. Clean, professional UI with a sidebar for uploaded docs and a main panel for results



Create multiple pages for different features
